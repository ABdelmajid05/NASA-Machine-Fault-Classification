# NASA Machine Fault Classification

This project uses Random Forest and XGBoost algorithms for predictive maintenance and fault classification using the NASA CMAPSS dataset.

## Algorithms
- Random Forest
- XGBoost
- SMOTE Oversampling

## Dataset
NASA CMAPSS Dataset

## Features
- Data preprocessing
- Fault labeling using RUL threshold
- Model training and evaluation
- Confusion matrix and classification metrics
